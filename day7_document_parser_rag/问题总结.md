## 2.为什么有时候要 `r`?  text = re.sub(r"\n{3,}", "\n\n", text)

不加 `r` （匹配时）

Python 会**提前把 `\t` 转义成真实的 Tab 空格**，再传给正则

加 `r`  （替换时）

Python **不处理 `\`**，直接把 `\t` 原样传给正则
