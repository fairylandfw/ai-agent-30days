## 1.为什么不直接按段落或句子切，最后再merge_units。而是用recrusive_split，先按段落，再按句子，然后再固定切，最后merge_units。如果光从句子完整性的角度，recursive_split似乎是更麻烦且没啥提升？

recursive_split其实是一个保险机制：

如果直接按句子切,merge 的时候可能得到：

```textile
chunk1 = 段落1 + 段落2的一部分
chunk2 = 段落2剩余部分 + 段落3开头
chunk3 = 段落3中间部分
```

段落边界被打乱了。



如果用recursive_split：

```textile
unit1 = 段落1
unit2 = 段落2
unit3 = 段落3的几个句子
unit4 = 段落3的几个句子
unit5 = 段落3的几个句子
```

主要是recursive_split兼顾了句子的完整，又照顾到短段落的完整性。

对一些异常情况，如过长的句子，无标点文本，超长段落，又进行了兜底
